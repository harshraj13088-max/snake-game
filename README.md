#  Snake Game in C++

A simple console-based Snake Game built using C++.

##  Features

- Snake movement using W, A, S, D
- Random food generation
- Score system
- Snake grows when food is eaten
- Wall collision detection
- Self-collision detection
- Game over system

##  Controls

| Key  Action |
|-----|--------|
| W | Move Up |
| A | Move Left |
| S | Move Down |
| D | Move Right |
| Q | Quit Game |

##  Technologies Used

- C++
- C++ STL
- Terminal

##  Concepts Used

- Structures
- Vectors
- Functions
- Loops
- Conditional statements
- Random numbers
- Collision detection
- Keyboard input
- Game loop
